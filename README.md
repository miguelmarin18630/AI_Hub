# AI Hub

Interfaz web para chat con modelos de IA (OpenCode, Claude Code, Ollama, OpenRouter, etc.).

## Estructura

- `aihub/` - Código fuente de la aplicación web
- `assets/` - Recursos del sistema (ICO, etc.)
- `marinweb-logo.svg` - Logo antiguo de la compañía
- `aihub-logo.svg` - Logo original de AI Hub (usado en el SVG generado)
- `aihub-logo-new.svg` - **Nuevo logo creado** (ver below)

## Nuevo logo

Se ha creado `aihub-logo-new.svg` con un diseño gráfico que reemplaza el anterior logo basado en el texto "＋". El nuevo logo presenta:

- Forma estilizada de la letra "A" con gradiente morado
- Motivo hexagonal central al estilo IA
- Detalles decorativos y sombra para profundidad
- Mantiene la paleta de colores morado (#7c5cff, #a277ff) de la interfaz

El logo ahora aparece en:
- El header superior de la aplicación
- La pantalla de login
